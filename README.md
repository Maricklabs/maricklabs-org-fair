# CICT Org Fair

Flutter app for browsing CICT organizations, events, memberships, and the
fair schedule. Events can be loaded from Contentful, Strapi, or Sanity using
`--dart-define-from-file=cms.json`.

The production version is `1.1.0` (build `2`). Keep `cms.json`,
`android/key.properties`, and signing keystores out of version control.
